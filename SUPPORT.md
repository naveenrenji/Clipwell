# Getting help

- **Questions and ideas:** open a [discussion](https://github.com/naveenrenji/Clipwell/discussions) (or an issue if discussions are not enabled yet).
- **Bugs:** use the [bug report template](https://github.com/naveenrenji/Clipwell/issues/new/choose). Use made-up examples; never paste real clipboard history.
- **Security problems:** report privately, see [SECURITY.md](SECURITY.md).
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).
